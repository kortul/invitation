# 🎉 Приглашение на свадьбу

Винтажное свадебное приглашение в виде одностраничного сайта с плавными анимациями.

## ✨ Особенности

- **Кинематографичное открытие**: замок → ботанические украшения → жених и невеста → текст
- **Плавные анимации**: каскадное появление элементов, параллакс, hover-эффекты
- **Идеально для мобильных**: адаптивная вёрстка, читаемая типографика, оптимизированные изображения
- **Винтажная эстетика**: антикварная бумага, оливково-шалфейные тона, ботаническая графика
- **Чистый код**: только HTML, CSS и vanilla JavaScript — никаких зависимостей

## 🚀 Быстрый старт

### Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/kortul/invitation.git
cd invitation
```

2. Откройте `index.html` в браузере (или используйте Live Server в VS Code)

### GitHub Pages

1. Зайдите в настройки репозитория на GitHub
2. Перейдите в раздел **Pages**
3. В разделе **Source** выберите ветку `main` и папку `/ (root)`
4. Нажмите **Save**
5. Через 1-2 минуты сайт будет доступен по адресу: `https://kortul.github.io/invitation/`

## 🎨 Как заменить иллюстрации

Все SVG-файлы в папке `assets/` — временные заглушки. Замените их на свои иллюстрации.

### Требования к новым файлам:

1. **Формат**: SVG (рекомендуется) или PNG с прозрачным фоном
2. **Размеры**: Сохраняйте пропорции оригинальных файлов
3. **Цвета**: Используйте ту же цветовую палитру (или адаптируйте в CSS)
4. **Имена файлов**: Оставьте те же имена для простоты замены

### Цветовая палитра (CSS переменные):

```css
--color-paper: #FDF8F3;      /* Античная кремовая бумага */
--color-olive: #6B7B5F;       /* Приглушённый оливковый */
--color-sage: #9CAF88;        /* Шалфей */
--color-dusty-rose: #C9A9A6;  /* Пыльная роза */
--color-ink: #2C2C2C;         /* Основной цвет текста */
--color-gold: #B8A98B;        /* Золотистый акцент */
```

### Пошаговая замена:

1. Подготовьте новые SVG/PNG файлы
2. Сохраните их в папку `assets/` с теми же именами
3. Или измените пути в `index.html` на новые имена файлов
4. Закоммитьте изменения: `git add . && git commit -m "Обновление иллюстраций"`
5. Отправьте на GitHub: `git push`

## 📱 Мобильная оптимизация

Сайт полностью адаптирован для мобильных устройств:

- Читаемая типографика на всех размерах экрана
- Ботанические рамки не перекрывают контент
- Изображения масштабируются без искажений
- Анимации работают плавно
- Горизонтальный скролл отсутствует
- Поддержка `prefers-reduced-motion` для пользователей с ограничениями

## 🎬 Анимации

### Последовательность открытия:

1. **0.3с** — Появляется замок (плавный зум + фейд)
2. **1.2с** — Проявляются ботанические рамки и угловые цветы
3. **2.0с** — Открываются жених и невеста
4. **2.8с** — Появляется текст с именами и датой

### Scroll-анимации:

- Секции плавно появляются при прокрутке
- Элементы таймлайна каскадно проявляются
- Параллакс-эффект для слоёв hero-секции
- Hover-эффекты для карточек и галереи
